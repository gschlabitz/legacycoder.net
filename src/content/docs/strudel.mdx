export const labTune = `setcps(1)
n("<0 1 2 3 4>*8").scale('G4 minor')
.s("gm_lead_6_voice")
.clip(sine.range(.2,.8).slow(8))
.jux(rev)
.room(2)
.sometimes(add(note("12")))
.lpf(perlin.range(200,20000).slow(4))`;

export const ambientTune = `note("<c a f e>(3,8)").jux(rev).room(2)`;

[Strudel](https://strudel.cc) is a JavaScript port of
[TidalCycles](https://tidalcycles.org): music written as code, evaluated live
while it plays. This page is my workbench for it. The editor below is the full
Strudel REPL running in the browser — change the code while it plays and the
pattern morphs on the next cycle.

- **Ctrl+Enter** (or **Cmd+Enter**) — play / update the pattern
- **Ctrl+.** — stop

Sounds and samples stream from the web on first play, so the lab needs a
network connection. Playback only starts after a click or keypress — browsers
refuse audio before a user gesture.

<StrudelRepl client:only="react" code={labTune} />

## Background music

The player below is the lightweight counterpart of the REPL above: no editor,
just a play/stop toggle for a fixed pattern, and it only downloads the Strudel
engine on first click. It exists so any page on the site can carry its own
tune later.
