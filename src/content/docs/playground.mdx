A scratch page for the farm-sim look of the [plant calendar](/plants/).
Tiles are cut from the packed sheets in `public/tiles/` with CSS only — one
`<span class="ts ts-farm t-42">` per tile. Indices match Kenney's individual
`Tiles/tile_00NN.png` files. Add sheets in `src/data/tilesheets.yaml`, then:

```bash
npm run tile-css
```

The `--px` variable is the size of one art pixel (2px, 3px at ≥800px
viewport, 4px at ≥1400px) — resize the window and everything rescales on
integer steps.

## Sample strip

A multi-row scene is one `.tile-scene` grid: set `--cols` and list tiles in
row-major order — they wrap into seamless rows automatically, like a tilemap
file. A bare `<span class="ts"></span>` (no sheet class) is an empty cell.
