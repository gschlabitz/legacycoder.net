title: "I don't write code anymore"
date: 2026-07-07
description: "I've lived through another paradigm shift: coding agents."
draft: true
---

The biggest change is that I barely write code anymore. Instead I discuss writing code with AI agents and then they go off and do their thing. At first a was resisting this, because I always thought coding WAS the job and the fun part of the job at that. However, it turns out that the the thing I enjoy is building and that coding agents take most of the boring grunt work off of my shoulders.



I stay at the concept level most of the time now, read a lot of code and specs and try to convince various agents that my idea and processes are the right way to go.



All in all my work has become more fun, because it removes a lot of the drudgery. It also feels more productive, because I can address technical debt much sooner than previously. I don't know for sure yet if it actually is more productive. I'm not involved in the business funding processes, so I don't actually know how the KPIs track.
